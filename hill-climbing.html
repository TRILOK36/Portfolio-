Smart Frame Hospital

A patient management desktop app built with Tkinter and SQLite, with a small frame-based reasoning layer that suggests a hospital department from a patient's symptoms.

Open live demo Download original Python source

The live demo runs real Python in your browser via PyScript's MicroPython interpreter (WebAssembly) — a genuine Python implementation, much lighter than full CPython, so it loads in a couple of seconds. Tkinter and SQLite are swapped for browser-friendly equivalents since those need a local OS, but the reasoning code is unchanged.

Overview

Smart Frame Hospital is a single-window Tkinter application for front-desk patient intake: it records patient details, assigns a room and bed, and keeps everything in a local SQLite database. The part I'm most interested in is the reasoning layer — a small frame-based knowledge structure (parent/child frames with slot inheritance) that backs a rule that suggests which department a patient should be routed to, based on the symptoms entered.

Features

  • Patient intake form — name, age, gender, blood group, allergies and symptoms, saved to SQLite.
  • Symptom-based department suggestion — matches entered symptoms against a knowledge base of departments to recommend where to route the patient.
  • Room & bed assignment tracked alongside each patient record.
  • Search & lookup by patient ID across saved records.
  • Full patient list view loaded from the database on demand.
  • Frame inspector — a view into the underlying frame/slot structure used for reasoning.

Tech stack

  • Python

Code: symptom → department reasoning

The core logic scores each known department by how many of its known symptoms overlap with what the patient reports, and returns the best match:

def suggest_department(symptoms):

    symptom_set = {
        item.strip().lower()
        for item in symptoms.split(",")
        if item.strip()
    }

                known_symptoms
            )
        )

        if score > highest_score:

            highest_score = score
            best_department = department

    return best_department

Code: frame structure

Patient and department data is modeled as Frame objects that can inherit slot values from a parent frame:

class Frame:

    def __init__(self, name, parent=None):
        self.name = name
        self.parent = parent
        self.slots = {}

    def set_slot(self, slot, value):
        self.slots[slot] = value

    def get_slot(self, slot):
        if slot in self.slots:
            return self.slots[slot]
        if self.parent is not None:
            return self.parent.get_slot(slot)
        return None

How to run it

  1. Download the source and unzip it.
  2. Make sure Python 3 is installed (Tkinter ships with most standard installs).
  3. From inside the project folder, run: python main.py
  4. The app creates/opens hospital.db automatically on first run.
